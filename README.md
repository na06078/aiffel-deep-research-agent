# 딥리서치 에이전트

LangGraph로 자료 조사·재위임·종합·평가를 실행하고, 작업을 픽셀 마을의 NPC와 타임라인으로 관찰하는 아이펠 실습 프로젝트입니다.

**이 저장소는 2026-11-11 현재 개발분을 제출하는 스냅샷입니다.** 미완료 사항을 숨기지 않고 이후 개발 내용을 커밋·푸시로 갱신합니다. 코드 공개는 최종 보고서 품질 합격이나 운영 배포 완료를 뜻하지 않습니다.

코드·문서·테스트·검증 요약은 포함하며, 대형 원사건/모델 입출력 저널은 삭제하지 않고 로컬에 보존합니다. 비교 폴더의 `원고.md`는 미합격 진단용 원고이며 최종 보고서가 아닙니다.

**최신 보고서 품질은 아직 미합격입니다.** 2026-11-11 실제 기준 연구는27요청으로4절·가시본문6,372자를 만들었지만 인용 지지 부족7개로 최종 제출을 차단했습니다. 자동 보완 상한3개를 임의 확대하지 않았습니다. 코드 검사 통과를 실제 보고서 합격으로 표시하지 않습니다. 최신 진행·비교·게시 상태는 [진행 현황](<📋 진행 현황.md>)을 따릅니다.

근거는 `02_구현/전체화면_스파이크/검증결과/제출/`에 있습니다. 과거 버전의 실제 성공과 최신 v5 미합격을 구별합니다. 미합격 원고를 최종보고서로 내려받게 우회하지 않습니다.

## 하는 일

- 고정 한국 근대사 34문서 또는 무료 웹 검색·수집 자료를 조사합니다.
- 기획 → 배치 → 조사 → 점검/재위임 → 종합 → 평가의 실행 기록을 저장합니다.
- NPC 말풍선과 작업대를 눌러 해당 사건의 프롬프트·입력·출력을 확인합니다.
- 품질 검토를 통과해 제출된 보고서를 열고 같은 정본의 Markdown·HTML·PDF를 내려받습니다.
- 실행 중 일반 지시는 즉시 개입하고, `/큐`는 현재 전체 연구의 제출 이후 처리합니다.
- 과거 기록·시간별 장면 재생·명시적 삭제를 지원합니다. 재생은 새 연구 실행이 아닙니다.
- 실패한 현재 작업은 원 기록을 보존하고 새 실행으로 재시도합니다. 대기 지시 취소는 선택한 항목만 제거하고 남은 큐의 순서·정지를 보존합니다.

새 문장-필수근거 생성·보완 범위 검토·큐 복구·비교 실험의 최종 검증 상태는 진행 현황의 최신 단위를 따릅니다.

## 실행 준비

검증한 환경은 Windows 11, Python 3.12.10, Node.js 26.7.0입니다. 다른 OS의 UI·글꼴·PDF는 별도 검증 전입니다. 아래 명령은 **프로젝트 루트의 PowerShell** 기준입니다.

### 1. 전용 Python 환경

Python 3.12와 `uv`가 있는 환경에서 실행합니다. 다른 프로젝트나 전역 Python에 설치하지 않습니다.

```powershell
uv venv .venv --python 3.12
uv pip install --python .venv/Scripts/python.exe -r '02_구현/전체화면_스파이크/설치패키지_고정.txt'
```

이미 쓰던 `.venv`가 있다면 새로 만들지 말고 기존 환경과 고정 버전을 먼저 확인합니다.

### 2. 고정 교안 자료

```powershell
& '.\.venv\Scripts\python.exe' '교안자료_준비.py' --download
& '.\.venv\Scripts\python.exe' '교안자료_준비.py' --check
```

고정 Git 커밋의 ZIP과 두 JSON의 SHA-256을 대조합니다. 정상 결과는 34문서·447,487자·428링크입니다. 이미 있는 파일은 덮어쓰지 않습니다. 자료가 다르다는 오류가 나면 기존 자료를 지우지 말고 경로·버전을 확인합니다.

자료 출처는 [교안 데이터 저장소](https://github.com/88chacha/deepresearch-agent-data)이며, 코퍼스 메타데이터는 한국어 위키백과·CC BY-SA 4.0·수집일 2026-09-21을 표시합니다. 제공된 예시 결과는 이 프로젝트의 실제 실험 결과가 아닙니다.

### 3. 인증과 최초 장부

```powershell
if (-not (Test-Path '.env')) { Copy-Item '.env.example' '.env' }
```

프로젝트 `.env`의 `OPENAI_API_KEY`에 **본인 키를 직접 입력**합니다. 키를 GitHub·화면 캡처·실행 로그에 넣지 않습니다. 예제 파일에는 실제 값이 없습니다.

```powershell
& '.\.venv\Scripts\python.exe' '실행준비.py' --init
& '.\.venv\Scripts\python.exe' '실행준비.py' --check
```

최초 빈 환경에만 호출 장부를 만듭니다. 기본 상한은 10,000시도·앱 추정 $20이며 필요하면 **최초 생성 시** `--max-attempts`·`--max-usd`로 더 낮게 지정합니다. 기존 장부의 정책·이력·미정산 예약은 바꾸지 않습니다. 기존 실행 자료만 있고 장부가 없으면 새 예산을 만들지 않고 복구를 요구합니다.

이 명령은 API 키를 읽거나 유효성을 확인하지 않고 모델도 호출하지 않습니다. 앱 상한은 OpenAI 계정 결제 상한이나 무료 혜택 보증이 아닙니다.

### 4. 화면과 PDF 브라우저 준비

```powershell
Push-Location '02_구현/전체화면_스파이크/화면'
npm ci
npm run build
Pop-Location
$env:PLAYWRIGHT_BROWSERS_PATH = "$PWD/.cache/playwright"
& '.\.venv\Scripts\python.exe' -m playwright install chromium
```

`npm run build`는 브라우저용 파일을 만드는 작업이며 EXE 제작이나 인터넷 배포가 아닙니다. PDF는 프로젝트 전용 Chromium을 사용합니다.

### 5. 서버 실행

8768 포트의 기존 서버가 없다면 실행합니다.

```powershell
Set-Location '02_구현/전체화면_스파이크'
& '..\..\.venv\Scripts\python.exe' -m 서버.연구앱 --port 8768
```

브라우저에서 <http://127.0.0.1:8768/#/control>을 엽니다. 종료는 **이 연구 서버 터미널에서 Ctrl+C**입니다. Hermes를 종료할 필요는 없습니다.

## 기본 사용

1. 하단에 질문을 입력하면 실제 모델 요청이 발생할 수 있습니다.
2. 기준 질문: `1894년에 일어난 주요 사건들은 무엇이고 각각의 원인은 무엇인가?`
3. `/데이터셋`·`/DB`·`/디비`는 고정 자료, `/웹`은 웹 자료를 선택합니다. 명령만 보내면 선택만 저장하며 연구를 시작하지 않습니다.
4. NPC·말풍선·작업대를 누르면 해당 사건의 상세가 열립니다.
5. 제출된 문서를 눌러 보고서를 열고 형식별로 다운로드합니다.
6. 햄버거 → 과거 기록에서 상세·기록 재생·삭제를 사용합니다. 재생 중에는 실행 변경을 막습니다.

화면의 품질 통과는 제공된 자료 범위에 대한 모델 검토와 코드 검사의 결과입니다. 외부 사실 전체가 참이라는 보증이 아니며, 불합격 초안은 최종 보고서로 제출하지 않습니다.

## 제출·재현의 경계

- `.env`, 원본 코퍼스 ZIP/JSON, 실행DB·장부·개인 보고서, `.venv`, `node_modules`, 재생성 가능한 빌드·캐시는 Git에서 제외합니다.
- 로컬 개발 이력을 유지하므로 과거 문서·검증 기록의 Windows 경로와 커밋 작성자 정보가 포함됩니다. 과거 기록의 수치·완료 표현은 해당 시점과 범위의 기록입니다.
- 실제 모델 호출에는 본인 API 키와 사용 가능 계정이 필요합니다. 무료 적용은 확인되지 않았습니다.
- 무료 검색 제공자의 제한·화면 구조 변경에 따라 웹 모드는 실패할 수 있습니다. 고정 자료 연구와 구별합니다.
- 앱의 동작·실험 결과·GitHub 게시·LMS 제출은 별개입니다. LMS 제출 버튼은 사용자가 최종 확인 후 누릅니다.
