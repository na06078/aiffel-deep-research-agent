# 딥리서치 에이전트

LangGraph로 자료 조사·재위임·종합·평가를 실행하고, 작업을 픽셀 마을의 NPC와 타임라인으로 관찰하는 아이펠 실습 프로젝트입니다.

**이 저장소는 2026-11-11 현재 개발분을 제출하는 스냅샷입니다.** 미완료 사항을 숨기지 않고 이후 개발 내용을 커밋·푸시로 갱신합니다. 코드 공개는 최종 보고서 품질 합격이나 운영 배포 완료를 뜻하지 않습니다.

코드·문서·테스트·검증 요약은 포함하며, 대형 원사건/모델 입출력 저널은 삭제하지 않고 로컬에 보존합니다. 비교 폴더의 `원고.md`는 미합격 진단용 원고이며 최종 보고서가 아닙니다.

**딥리서치 교안의 제출 대응과 제품 품질 고도화를 분리합니다.** 최신 제출 보완에서는 Q1/Q4/Q6의 단일·멀티 및 역할 소거7조건을203요청으로 실행해 모든 초회12읽기와2,000자 이상 원고를 확인했습니다. 추가 AI 품질 검토는 정상 부정5/검토 응답 무효2로 최종 보고서를 차단했으며, 이를 합격으로 바꾸지 않았습니다. 자동 보완 상한3개도 확대하지 않았습니다. 최신 진행·게시 상태는 [진행 현황](<📋 진행 현황.md>)을 따릅니다.

근거는 `02_구현/전체화면_스파이크/검증결과/제출/`에 있습니다. 과거 버전의 실제 성공과 최신 v5 미합격을 구별합니다. 미합격 원고를 최종보고서로 내려받게 우회하지 않습니다.

## 하는 일

- 고정 한국 근대사 34문서 또는 무료 웹 검색·수집 자료를 조사합니다.
- 기획 → 배치 → 조사 → 점검/재위임 → 종합 → 평가의 실행 기록을 저장합니다.
- NPC 말풍선과 작업대를 눌러 해당 사건의 프롬프트·입력·출력을 확인합니다.
- 품질 검토를 통과해 제출된 보고서를 열고 같은 정본의 Markdown·HTML·PDF를 내려받습니다.
- 실행 중 일반 지시는 즉시 개입하고, `/큐`는 현재 전체 연구의 제출 이후 처리합니다.
- 과거 기록·시간별 장면 재생·명시적 삭제를 지원합니다. 재생은 새 연구 실행이 아닙니다.
- 실패한 현재 작업은 원 기록을 보존하고 새 실행으로 재시도합니다. 대기 지시 취소는 선택한 항목만 제거하고 남은 큐의 순서·정지를 보존합니다.

새 문장-필수근거 생성·보완 범위 검토·큐 복구·비교 실험의 최종 검증 상태는 진행 현황의 최신 단위를 따릅니다.

## 최신 교안 비교 — 2026-11-11

- **Q1:** `운요호 사건은 무엇인가?` — 단일 문서 중심 질문

1. **같은 조건과 실제 소비량을 구별합니다.** 모두4절×3읽기·최대2라운드·절당16관계·보완1회입니다. Q1 멀티와 Q6 역할 소거는 부족절 재위임 때문에3건을 더 읽었습니다. 총 읽기까지 정확히 같은 주 대조는 Q4입니다. 같은 한도를 주었다고 실제 사용량까지 같다고 쓰지 않습니다.
2. **중복률은 실제 조사자-문서 쌍으로 계산했습니다.** 단일이12문서를 한 번씩 읽은 뒤4절에 공유한 것은48번 읽은 일이 아닙니다. 원 quality의75%는 보존하고 표에는 사건 저널 후처리의0%를 사용합니다. 같은 조사자의 재읽기율과 조사자 간 중복률도 별도 필드입니다. 이것만으로 단일의 내용 품질이 더 좋다고 결론내리지 않습니다.
3. **근거율의 원식을 결과 비교에서 제외했습니다.** v5는 문장 뒤에 인용 표식을 붙이지만 교안식 문장 분할은 이를 떨어뜨려 과소 계산합니다. 원 `근거율`·허위인용·읽고안쓴·편중 등은 JSON에 그대로 보존합니다. 표식 존재와 주장의 의미적 지지는 다른 검사이며, 낮은 원식 근거율을 사실 오류율로 해석하지 않습니다.
4. **품질 실패를 숨기지 않았습니다.** Q4 멀티·Q6 단일은 검토 발췌 계약 무효로 판정 불가이고, 나머지5조건은 정상 구조의 부정 판정입니다. 인과·해석의 근거 지지와 검토 메타데이터 전달 개선은 후속 개발로 남습니다. 수업 실습 원고가 생성됐다고 제품 최종 보고서까지 합격한 것은 아닙니다.
5. **교안과 달리 선택한 실험도 표시합니다.** 이전 width2/depth1은 총량도 줄이는 실험이며 교안의2×4 대4×2 동일총량 실습과 같지 않습니다. 배정/구역을 각각 끈 조건도 교안의 동시 소거와 구별합니다. 이 프로젝트에서 승인한 단일요인 비교이며 원 교안 실험을 그대로 전수 수행했다는 뜻이 아닙니다.

- 근거율·중복률·격리율은 교안식 자동 대리지표입니다. 인용 표식 위치와 문장 분할에 영향을 받으며 의미적 지지율이나 실제 정보 유출률이 아닙니다. 낮은 수치나 호출 수만으로 아키텍처의 우열을 주장하지 않습니다.
- 일부 정상 메타데이터/의역에 대한 검토의 과도한 거절 가능성도 별도 조사 대상입니다. 원 판정을 수정하거나 차단 원고를 최종보고서로 내보내지 않았습니다.
- [구조화 집계](02_구현/전체화면_스파이크/검증결과/제출/비교/final02/집계.json)와 [실험 당시197소스](02_구현/전체화면_스파이크/검증결과/제출/비교/final02/실험소스.zip)를 보존합니다. 이후 import/동일 스키마 표현 정리는 별도 최종 회귀로 검사했으며 새 실모델 성공으로 표시하지 않습니다.

## 교안 비교 재현

아래 실행 준비를 마친 뒤 프로젝트 루트 PowerShell에서 사용합니다. `--check`·`--prepare`는 제공자를 만들지 않습니다. **`--execute`는 실제 모델을 호출하며 비용이 발생할 수 있습니다.** 새 라벨과 같은 질문을 유지하고, Q1/Q6는 질문키와 라벨을 함께 바꿉니다. 저장된 실패도 `--resume`에서 재전송하지 않습니다.

```powershell
$py = '.\.venv\Scripts\python.exe'
$runner = '02_구현/전체화면_스파이크/검증/비교실험_실행.py'
$ledger = '03_실행데이터/실제연구/호출예산.sqlite3'
& $py $runner --check --ledger $ledger --question-key Q4
& $py $runner --prepare --ledger $ledger --label 재현_Q4 --question-key Q4
& $py $runner --execute --ledger $ledger --label 재현_Q4 --question-key Q4 --arm baseline
& $py $runner --execute --resume --ledger $ledger --label 재현_Q4 --question-key Q4 --arm single
```

이 저장 실험은 외부 순차 러너에서 조건당360초를 적용했습니다. 일반 비교 CLI의 timeout 기본값은1800초이며, 제공자 대기까지 포함한 제한시간이지 순수 연산시간이 아닙니다. 원 결과를 바꾸지 않는 중복률 재계산은 다음처럼 실행합니다.

```powershell
& $py '02_구현/전체화면_스파이크/검증/교안비교_후처리.py' '.cache/보고서품질_검증/실모델점검/제출_비교/재현_Q4/single/실행아카이브.json'
```

## 실행 준비

검증한 환경은 Windows 11, Python 3.12.10, Node.js 26.7.0입니다. 다른 OS의 UI·글꼴·PDF는 별도 검증 전입니다. 아래 명령은 **프로젝트 루트의 PowerShell** 기준입니다.

### 1. 전용 Python 환경

Python 3.12와 `uv`가 있는 환경에서 실행합니다. 다른 프로젝트나 전역 Python에 설치하지 않습니다.

```powershell
uv venv .venv --python 3.12
uv pip install --python .venv/Scripts/python.exe -r '02_구현/전체화면_스파이크/설치패키지_고정.txt'
```

이미 쓰던 `.venv`가 있다면 새로 만들지 말고 기존 환경과 고정 버전을 먼저 확인합니다.

### 2. 고정 교안 자료

```powershell
& '.\.venv\Scripts\python.exe' '교안자료_준비.py' --download
& '.\.venv\Scripts\python.exe' '교안자료_준비.py' --check
```

고정 Git 커밋의 ZIP과 두 JSON의 SHA-256을 대조합니다. 정상 결과는 34문서·447,487자·428링크입니다. 이미 있는 파일은 덮어쓰지 않습니다. 자료가 다르다는 오류가 나면 기존 자료를 지우지 말고 경로·버전을 확인합니다.

자료 출처는 [교안 데이터 저장소](https://github.com/88chacha/deepresearch-agent-data)이며, 코퍼스 메타데이터는 한국어 위키백과·CC BY-SA 4.0·수집일 2026-09-21을 표시합니다. 제공된 예시 결과는 이 프로젝트의 실제 실험 결과가 아닙니다.

### 3. 인증과 최초 장부

```powershell
if (-not (Test-Path '.env')) { Copy-Item '.env.example' '.env' }
```

프로젝트 `.env`의 `OPENAI_API_KEY`에 **본인 키를 직접 입력**합니다. 키를 GitHub·화면 캡처·실행 로그에 넣지 않습니다. 예제 파일에는 실제 값이 없습니다.

```powershell
& '.\.venv\Scripts\python.exe' '실행준비.py' --init
& '.\.venv\Scripts\python.exe' '실행준비.py' --check
```

최초 빈 환경에만 호출 장부를 만듭니다. 기본 상한은 10,000시도·앱 추정 $20이며 필요하면 **최초 생성 시** `--max-attempts`·`--max-usd`로 더 낮게 지정합니다. 기존 장부의 정책·이력·미정산 예약은 바꾸지 않습니다. 기존 실행 자료만 있고 장부가 없으면 새 예산을 만들지 않고 복구를 요구합니다.

이 명령은 API 키를 읽거나 유효성을 확인하지 않고 모델도 호출하지 않습니다. 앱 상한은 OpenAI 계정 결제 상한이나 무료 혜택 보증이 아닙니다.

### 4. 화면과 PDF 브라우저 준비

```powershell
Push-Location '02_구현/전체화면_스파이크/화면'
npm ci
npm run build
Pop-Location
$env:PLAYWRIGHT_BROWSERS_PATH = "$PWD/.cache/playwright"
& '.\.venv\Scripts\python.exe' -m playwright install chromium
```

`npm run build`는 브라우저용 파일을 만드는 작업이며 EXE 제작이나 인터넷 배포가 아닙니다. PDF는 프로젝트 전용 Chromium을 사용합니다.

### 5. 서버 실행

8768 포트의 기존 서버가 없다면 실행합니다.

```powershell
Set-Location '02_구현/전체화면_스파이크'
& '..\..\.venv\Scripts\python.exe' -m 서버.연구앱 --port 8768
```

브라우저에서 <http://127.0.0.1:8768/#/control>을 엽니다. 종료는 **이 연구 서버 터미널에서 Ctrl+C**입니다. Hermes를 종료할 필요는 없습니다.

## 기본 사용

1. 하단에 질문을 입력하면 실제 모델 요청이 발생할 수 있습니다.
2. 기준 질문: `1894년에 일어난 주요 사건들은 무엇이고 각각의 원인은 무엇인가?`
3. `/데이터셋`·`/DB`·`/디비`는 고정 자료, `/웹`은 웹 자료를 선택합니다. 명령만 보내면 선택만 저장하며 연구를 시작하지 않습니다.

5. 제출된 문서를 눌러 보고서를 열고 형식별로 다운로드합니다.
6. 햄버거 → 과거 기록에서 상세·기록 재생·삭제를 사용합니다. 재생 중에는 실행 변경을 막습니다.
