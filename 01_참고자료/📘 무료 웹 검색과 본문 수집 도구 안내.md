# 무료 웹 검색과 본문 수집 도구 안내

- 작성일: 2026-11-06, 한국 시간
- 대상: 이 프로젝트에서 처음 웹 검색 기능을 연결하는 학습자
- 현재 작업과 승인 상태: [진행 현황](<../📋 진행 현황.md>)
- 검증 상태: 문서로 확인한 도구의 역할을 설명한다. 이 파일의 최초 작성 시점에는 `ddgs`·Trafilatura를 설치하거나 실제 무료 검색을 시험하지 않았다. 설치·실측 결과는 기술 명세와 진행 현황의 최신 기록을 따른다.

## 1. 한 줄로 이해하기

**DDGS는 자료가 있는 웹주소를 찾고, Trafilatura는 받아 온 페이지에서 주요 본문을 추출한다.** 둘 다 GPT처럼 보고서를 생성하는 LLM은 아니다.

라이브러리는 Python 프로그램에서 불러다 쓰는 기능 묶음이다. Windows에 별도 AI 앱을 설치하는 것이 아니라 이 프로젝트의 `.venv/`에 패키지를 넣고 기존 Python 서버에서 호출한다. 이번 작업은 다른 프로젝트나 시스템 전역 Python에 설치하지 않는다.

## 2. DDGS — 검색 담당

DDGS는 여러 웹 검색서비스의 결과를 모으는 Python 라이브러리다. 공식 예제는 API 키 없이 `DDGS().text(...)`를 호출하는 방법을 보여준다. 우리 앱에서는 검색 기능을 사용해 제목·URL·짧은 설명을 받는 역할로 검토한다.[13]

예를 들어 ‘최근 AI 정책 변화를 조사해 줘’라는 질문에서 읽을 만한 공지·기사의 위치를 찾는 단계다. 이 예시는 동작 설명이며 실제 검색 결과를 제시한 것이 아니다.

- 자체 검색 색인을 새로 만드는 도구는 아니다.
- 검색 결과의 짧은 설명을 받았다고 해당 페이지 본문을 읽은 것은 아니다.
- 현재 버전의 실제 검색 백엔드·요청/재시도 동작을 설치 후 확인하고 연결한다. 이름만 보고 DuckDuckGo 하나만 호출한다고 가정하지 않는다.
- 공식 README는 교육용이라는 주의 문구를 둔다. 현재 실습의 동작 확인과 향후 서비스 운영·약관 검토는 구분한다.[13]

## 3. Trafilatura — 본문 추출 담당

Trafilatura(트라필라투라)는 HTML에서 주요 본문과 제목·작성자·날짜 같은 메타데이터를 추출하는 도구다. 메타데이터는 본문에 붙는 식별 정보라는 뜻이며, 원문에 없거나 추출하지 못하면 미확인으로 남긴다.[14]

웹페이지에는 본문 외에도 메뉴·광고·관련 글·하단 안내가 섞여 있다. 단순히 HTML 태그만 지우는 것보다 주요 본문을 골라내는 기능이 필요해 이 도구를 검토한다. 추출이 항상 완벽하거나 페이지 전체를 빠짐없이 보존한다고 보장하지 않는다.

우리 앱에서는 기존 `httpx`가 공개 페이지의 HTML을 받고, Trafilatura가 그 받은 내용을 본문 중심으로 정리하게 한다. 따라서 다운로드와 추출의 실패를 따로 확인할 수 있다. Trafilatura가 본문의 사실 여부를 검사하거나 AI 요약을 만들어 주는 것은 아니다.

## 4. 우리 앱에서의 역할 분담

| 담당 | 역할 | 결과 |
|---|---|---|
| 사용자·코디네이터 | 질문을 정리하고 조사 업무 배정 | 조사 질문·검색어·담당 절 |
| DDGS | 웹 검색서비스에서 후보 찾기 | 제목·URL·검색 결과 설명 |
| httpx | 선택한 공개 웹페이지 받기 | 응답 상태·최종 URL·HTML |
| Trafilatura | 받은 HTML에서 주요 본문 추출 | 본문·확인 가능한 메타데이터 |
| 기존 OpenAI 모델 | 본문을 읽고 메모·절 원고·보고서 작성 | 생성 내용·사용량 |
| 앱 코드·SQLite | 실제 수집과 생성 기록 연결 | 출처·수집 시각·본문/해시·실패 상태·실행 이력 |
| 기존 마을 화면 | 실제 이벤트를 표현 | 말풍선·상세·타임라인·보고서 열람 |

비유하면 DDGS는 도서관에서 책의 위치를 찾는 역할이고, Trafilatura는 가져온 자료에서 주요 본문을 꺼내는 역할이다. 비유와 달리 도구가 원문을 이해하거나 진실을 판정하는 것은 아니다.

## 5. ‘무료’와 ‘무제한’의 구분

이번 우선안은 월간 무료 credits를 주는 상업 검색 API가 아니라 무료 라이브러리를 직접 사용하는 구성이다. 검색·본문 추출 서비스의 건별 API 이용료를 내지 않는 방향이며 내 PC의 자원·네트워크 비용은 별개다.

다음 제한은 여전히 있을 수 있다.

- 검색엔진이 자동 요청에 응답하지 않거나 일시적으로 제한할 수 있다.
- 페이지가 로그인을 요구하거나 차단·접근 제한을 반환할 수 있다.
- JavaScript로 나중에 본문을 만드는 페이지는 받은 HTML에 본문이 없을 수 있다.
- 본문 추출 결과가 비어 있거나 메뉴·일부 문단만 남을 수 있다.

SearXNG 같은 자체 호스팅 검색 중계도 원천 검색엔진의 CAPTCHA·차단을 없애 주지는 않는다. 공개 SearXNG 인스턴스는 JSON 결과 자체를 꺼 둘 수도 있다.[11][12] SearXNG는 이번 첫 설치 대상이 아니며 무료 경로에서 실제 문제가 확인될 때 별도 선택한다.

**검색 결과 없음·페이지 수집 실패·본문 추출 실패를 구별하고, 읽지 못한 페이지를 읽었다고 처리하지 않는다.** 무료 경로의 실패를 유료 API로 자동 전환하지 않는다. 무한 반복 방지·요청 간격·시간/크기 상한은 서비스 요금 한도와 다른 안전장치다.

OpenAI 모델 요금은 별개다. 기존 모델·100회 호출 상한·앱 추정 비용 $2 상한을 유지하고 이번 기능 추가 때문에 초기화하거나 새 독립 예산을 만들지 않는다. 실제 무료 토큰 적용과 실제 청구액은 별도 확인 사항이다.

## 6. 개발·검증 순서

1. 기존 작업·기술 명세와 진행 현황에서 무료 웹 검색을 다음 단계로 기록한다. 보고서 생성 품질 개선은 이후로 미룬다.
2. 프로젝트 전용 환경의 기존 패키지를 확인한 뒤 DDGS·Trafilatura 추가의 의존성 영향을 검사한다.
3. 검색어4개와 공개 본문 최대6페이지로 실제 무료 검색·수집을 시험한다. 이 단계는 모델 호출0이다.
4. 통과한 경로를 기존 연구 그래프·출처 저장·마을 상세/기록에 연결한다. 기존 교안34문서 모드와 과거 보고서는 보존한다.
5. 실제 연구는 필요한 요청 수를 산출해 별도 실행 범위를 확정한 뒤 검사한다. 새로고침·재생·출처 열람이 검색이나 모델을 재호출하지 않아야 한다.
6. 회귀·실제 사용자 경로·문서·검증 근거를 확인하고 승인된 로컬 Git으로 기록한다.

설계·설치·무료 검색 성공·본문 추출 성공·실제 모델 연구·보고서 내용 품질은 서로 다른 검증 단계다. 무료 검색이 된 것만으로 최종 보고서 품질까지 검증했다고 쓰지 않는다.

## 7. 최초 실측에서 확인한 점

- 프로젝트 전용 환경에 DDGS 9.16.1·Trafilatura 2.3.1을 설치했다. 기존 63개 패키지 버전은 바꾸지 않았고 추가 후 78개 호환 검사와 기존 모델/예산 관련 42개 시험을 통과했다.
- 첫 검색은 네 질문 중 하나만 성공했다. 나머지는 검색엔진의 보안검사/제한 응답이었다. 따라서 ‘키 없이 설치할 수 있다’는 것과 ‘이 PC에서 검색을 안정적으로 계속할 수 있다’는 것은 별도 검증 사항이다.
- 성공한 검색에서 발견한 Python 한국어 문서는 실제로 내려받아 주요 본문 1,621자를 추출했다. 이것은 한 문서의 성공이며 모든 사이트의 성공 보장은 아니다.
- 추출 도구가 날짜처럼 보이는 값을 반환해도 발행일이 아닐 수 있다. 이 문서에서는 하단 저작권 연도와 겹치는 날짜가 나와 원시 후보로만 기록했다. 확인되지 않은 날짜를 보고서의 최신성 근거로 쓰지 않는다.
- 첫 실패를 보존한 뒤 같은 네 질문을 Yahoo 공개 검색으로 재검증해 모두 검색 결과를 얻었다. 따라서 DDGS 하나를 사용하더라도 실제 연결한 검색 엔진별로 성공·실패가 다를 수 있다. 고유 질문은 네 개이고 검색 시도는 처음과 재검증을 합해 여덟 번이다.
- 대안의 실제 검색 결과에서 추가 문서를 선택해 전체 여섯 페이지에서 텍스트를 추출했다. 그중 다섯 문서는 주요 본문 표본을 확인했지만, 공공데이터포털 한 문서는 추출이 오류코드 표에 편중됐다. **텍스트가 길게 나왔다는 것과 필요한 주요 본문을 제대로 얻었다는 것도 서로 다르다.**
- 제한된 무료 연결 실험은 통과했지만 지속적인 무제한 검색·문서 전문의 완전성·현재 앱의 전체 웹 조사 기능까지 검증한 것은 아니다. 새 모델 호출은 하지 않았다. 최신 판정은 진행 현황과 실제 검증 JSON을 따른다.
