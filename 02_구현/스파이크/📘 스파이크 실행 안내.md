# 스파이크 실행 안내

- 검사 기준일: 2026-11-05, 한국 시간. 실제 기동 시각·PID·서버 상태는 인계 JSON을 참조한다.

## 지금 열기

- 에셋 실험: <http://127.0.0.1:8766/#/assets>
- 실행 제어: <http://127.0.0.1:8766/#/control>

인계 검사 시 로컬 서버와 브라우저 렌더링을 확인했다. 이미 접속된다면 서버를 중복 실행하지 않는다. 실제 사용자 브라우저·LMS는 조작하지 않았으며 시험은 별도 Chromium에서 수행했다.

**이것은 두 스파이크의 실행본이다. 서버·SQLite·LangGraph·SSE·파일은 실제로 작동하지만 모델 응답과 조사 자료는 명시적인 합성 대역이다. `gpt-5.6-luna`·교안 코퍼스의 실제 리서치 성공으로 보지 않는다.** 키를 읽거나 실제 GPT·이미지 생성 요청을 보내지 않는다.

## 1. 무료 에셋 장면 확인

1. `에셋 실험`에서 **이동 보기 → 작업 보기 → 문서 운반**을 눌러 본다. 각 동작은 따로 실행할 수도 있다.
2. NPC 말풍선 전체 또는 본문이 `...`인 작업대 말풍선을 누른다. 오른쪽에 선택한 장면의 입력·출력·시각이 표시된다.
3. 내려놓은 종이를 누르면 합성 문서 전달 사건을 확인할 수 있다.
4. **처음으로**는 장면 위치를 되돌리는 조작이다. 서버 기록을 삭제하는 기능이 아니다.

이 모드는 서버 연구 작업·모델 대역 호출을 만들지 않는다. PNG는 Kenney CC0 원본이며 인물은 정면 포즈다. 움직임·작업·운반은 코드 연출이고 방향별 걷기 프레임을 확보했다는 뜻은 아니다.

## 2. 지시 개입·늦은 응답·큐 확인

하단 입력은 실제 로컬 서버로 보낸다. 에셋 화면에서 전송해도 실행 제어 화면으로 이동한다.

1. `테스트 A를 시작해 주세요`를 보낸다. 네 조사관의 **대역 응답 대기**가 생긴다.
2. A의 응답을 완료하지 않은 채 `테스트 B로 계획을 변경해 주세요`를 보낸다. 같은 실행의 버전이 바뀌고 B 계획·배정이 저장된다.
3. `/큐 테스트 C를 다음에 실행해 주세요`를 보낸다. 이 지시는 대기열에 보관된다.
4. **현재 1건 완료**를 누르면 조사 한 건만 완료된다. 이때 C가 시작되면 안 된다.
5. **현재 모두 완료**로 나머지를 해제한다. B의 합성 보고서 파일·제출 기록이 확정된 뒤 C가 시작된다. NPC 운반·문서 열람을 기다리지는 않는다.
6. **이전 응답 돌려주기**를 누르면 A의 늦은 결과가 이력에 남지만 B의 원고·평가·정본을 바꾸지 않는다.
7. 종이 또는 확정 문서 항목을 눌러 같은 보고서를 열고 **이 문서 Markdown 다운로드**로 받는다.

일반 입력은 즉시 개입이고 `/큐` 뒤에는 다음 지시를 적는다. `202 접수`와 `instruction.applied`(새 계획·배정 반영)는 다르다. 시험 버튼은 가상의 요청 ID가 아니라 실제로 대기 중인 대역 gate ID를 해제한다.

### 실패·품질·복원

- **실패 응답**: 의도적 대역 오류를 발생시킨다. 현재 실행이 실패하고 대기열은 보존·일시정지된다.
- **불합격 초안**: 분량·인용 등 필수 검사를 통과하지 못하는 합성 후보를 만든다. 초안은 남지만 최종 보고서를 제출하지 않는다.
- **큐 계속**: 사용자가 명시적으로 대기열을 재개한다. 정지 중 일반 지시는 바로 처리해도 기존 큐 정지를 해제하지 않는다.
- **현재 실행 취소**: 표시된 실행·버전만 논리적으로 취소한다. 실제 제공자의 물리적 취소 성공을 뜻하지 않는다.
- **새로고침**: 같은 실행·버전과 사건을 다시 읽는다. 새 작업·모델 호출을 만들지 않는다.
- **서버 재시작**: 미완료 실행은 `interrupted`(중단됨)로 남고 큐는 정지된다. 모델 대역도 자동 재호출하지 않는다.

현재 역할 표시는 현재 실행·버전만 나타낸다. 이전 문서는 별도로 남고 사건 목록에는 현재/이전 실행·버전을 표시한다. 오른쪽 상세는 사용자가 선택한 과거 사건도 계속 고정할 수 있다. 화면 시각은 KST이며 상세에 저장된 UTC 원본도 함께 둔다.

## 3. 서버가 꺼져 있을 때

다음은 **Windows PowerShell** 명령이다. 기존 서버가 켜져 있으면 다시 실행하지 않는다.

```powershell
Set-Location 'C:\my vault\ME\1. Note\Hermes\Aiffel_Work\02_노드실습\딥리서치_에이전트\02_구현\스파이크'
& '..\..\.venv\Scripts\python.exe' -m uvicorn '서버.앱:create_app' --factory --host 127.0.0.1 --port 8766 --workers 1
```

이 명령으로 직접 연 서버는 해당 콘솔에서 `Ctrl+C`로 종료한다. Hermes의 백그라운드 서버를 끝내려면 해당 스파이크 서버만 중지해 달라고 요청한다. 다른 앱·Hermes를 종료할 필요는 없다.

프론트 수정 시 `화면/`에서 `npm run build`를 실행한다. build는 브라우저용 파일을 만드는 과정이며 EXE 제작이나 인터넷 배포가 아니다. 의존성 재구성은 `필수패키지.txt`, `설치패키지_고정.txt`, `화면/package-lock.json`을 기준으로 별도 환경에서 한다.

## 4. 저장 위치와 검증 근거

- 사용자 실행 데이터·합성 보고서: 프로젝트의 `03_실행데이터/스파이크/`. 자동 삭제하지 않으며 Git에서 제외한다.
- 시험용 데이터: `.cache/스파이크_통합검사/`, `검증결과/임시*/`. 실제 사용자 데이터와 분리한다.
- 실제 소켓·브라우저·다운로드·재시작의 최종 근거: `검증결과/최종검사/통합_실제실행.json`과 같은 폴더의 화면 캡처.
- 실제로 켜 둔 인계 실행본: `검증결과/사용자실행본_확인.json`.
- 환경·에셋의 원본 픽셀과 버전: `검증결과/환경과에셋_확인.json`, `화면/public/에셋/에셋_목록.json`.

검증 계층은 Python 테스트 20개, 화면 단위검사 9개, 실제 통합 시나리오 14개로 구분한다. 이를 서로 더해 하나의 동질적인 테스트 수로 표현하지 않는다. 실제 모델 호출·연구 정확도·운영 배포는 검사한 것이 아니다.

## 5. 정식 앱과 다른 점

- 선택 모델의 인증·파라미터·호출 예산·실제 추론과 교안 코퍼스 리서치·재위임·비교 실험은 아직 연결하지 않았다.
- 실제 여섯 LangGraph 노드와 Send 병렬 경로를 쓰지만 내용은 합성 대역이다. 앱의 SQLite 저널 복원과 운영용 LangGraph 체크포인터 복원은 다르다.
- 장면은 정면 포즈·단일 이동/운반을 확인하는 작은 실험이다. 모든 역할의 개별 공간 활동·방향별 보행을 완성한 것이 아니다.
- 문서 뷰어는 안전하게 원문 Markdown을 표시한다. 정식 드로어·과거 기록 팝업·HTML/PDF 변환은 후속 범위다.
- 긴 입출력을 선택하면 인스펙터 때문에 페이지가 길어질 수 있다. 입력은 문서 스크롤로 접근하며, 정식 화면의 정보 밀도·장면 구성은 후속 검토 대상이다.
- 단일 loopback 작업자용이다. 다중 사용자·서버 확장·인증·운영 보안·DB/파일 장애 원자성을 완료했다고 보지 않는다.

원래 요구사항과 승인·현재 판정은 루트의 작업 명세서·기술 명세서·진행 현황을 따른다.
