# 전체 화면 마을 스파이크 실행 안내

확인일: 2026-11-06, 한국 시간.

## 바로 열기

- 실행 제어: <http://127.0.0.1:8766/#/control>
- 에셋 장면: <http://127.0.0.1:8766/#/assets>

이번 실행본은 **화면과 실행 제어를 검증하는 스파이크**입니다. 화면을 임시로 시험해 보는 구현이며, 실제 GPT 연구 결과가 아닙니다. FastAPI·LangGraph·SQLite·SSE·파일 저장은 실제로 연결했지만 모델 응답과 조사 자료는 명시적인 테스트 대역입니다. 실제 모델 요청은 0입니다. 선택 모델의 인증·무료 사용 적용·실제 연구·HTML/PDF 변환 등 정식 앱의 요구는 그대로 남아 있고, 이번 완료 범위에 포함하지 않습니다.

## 화면 사용

마을이 브라우저 작업 영역 전체입니다. 왼쪽 위 햄버거와 오른쪽 위 작은 `모의 응답` 표시, 하단 입력만 기본적으로 보입니다. 상세나 큐 때문에 마을이 작아지지 않습니다.

- NPC 또는 말풍선: 해당 실행·버전의 사건을 중앙 팝업으로 엽니다.
- 작업대의 `...` 말풍선: 실제 코드 처리 사건의 입력·반환을 엽니다.
- `(클릭해서 더 자세히)` 글자뿐 아니라 말풍선 전체를 누를 수 있습니다.
- 제출 문서: 정확한 보고서 ID의 본문과 `Markdown 다운로드`를 엽니다.
- 팝업의 X 또는 Escape: 창만 닫습니다. 입력과 실행은 유지합니다.
- 긴 상세·기록은 팝업 안에서 스크롤합니다. 하단 입력은 계속 사용할 수 있습니다.

햄버거 메뉴에는 다음 기능이 있습니다.

| 메뉴 | 기능 |
|---|---|
| 장면 도구 | 에셋 모드의 이동·작업·문서 운반·처음으로 |
| 실행/큐 | 현재 질문·상태·계획·대기열·일시정지 사유와 `큐 계속` |
| 과거 기록 | 보존된 실행 목록 → 자세히 보기 → 같은 창의 목록 복귀 |
| 사건 기록 | 사건을 선택하여 고정된 원본 상세 열람 |
| 제어 도구 | 대역 응답 완료·이전 응답 해제·실패·불합격·현재 실행 취소 |
| 안내 | 모드·조작·보존 정책 안내 |

모드 전환도 메뉴 안에 있습니다. 에셋 실험은 합성 연출만 변경하며 서버 연구를 실행하지 않습니다. 실제 하단 지시를 시험하려면 **실행 제어**를 선택합니다.

## 실행 제어 시험 순서

1. 하단에 조사 지시 A를 입력하고 `지시 보내기`를 누릅니다.
2. 실제 로컬 그래프가 계획과 네 조사관 작업을 만듭니다. 응답은 시험 제어를 위해 대기합니다. 움직이는 것만 보고 실제 모델이 추론한다고 해석하지 않습니다.
3. 메뉴 → `제어 도구` → `현재 모두 완료`를 누르면 현재 대역 응답이 돌아오고 초안·검사·정본 저장·제출로 이어집니다.
4. 종합자가 문서를 운반해 놓으면 문서를 누릅니다. 뷰어와 다운로드는 같은 확정 Markdown입니다. 다운로드 파일을 다시 열어 볼 수 있습니다.

### 즉시 개입과 큐

- **일반 지시 B**: A가 기다리는 중에도 현재 계획·배정을 새 버전으로 바꿉니다. A의 원격 요청 내용을 소급 수정하는 기능이 아니라 새 지시를 적용하고 늦은 A의 결과가 정본을 덮지 못하게 하는 제어입니다.
- **`/큐 다음 조사`**: 현재 전체 보고서가 검사·저장·서버 제출된 뒤 진행합니다. 조사관 한 명의 응답이나 NPC 운반 완료를 기다리는 계약이 아닙니다.
- **이전 응답 돌려주기**: 이전 대기 응답을 실제로 반환시켜 적용 차단을 관찰합니다. 기록은 남지만 현재 원고·평가·정본에 섞지 않습니다.
- **실패 응답 / 불합격 초안 / 현재 실행 취소**: 해당 결과와 초안을 보존하고 큐를 일시정지합니다. 불합격 초안은 최종 문서로 제출하거나 다운로드하지 않습니다.
- **큐 계속**: 사용자가 명시적으로 일시정지를 풉니다. 정지 중 일반 지시를 보내도 기존 큐 정지는 자동으로 풀리지 않습니다.

새로고침은 상태 조회·사건 재구독만 하며 연구를 새로 시작하지 않습니다. 서버 재시작은 기록을 복원하되 진행 중이던 불명 작업은 `interrupted`, 큐는 정지로 남기고 대역/모델을 자동 재실행하지 않습니다.

## 서버를 다시 켜야 할 때

이미 8766 서버가 실행 중이면 다시 시작하지 말고 위 주소를 사용합니다. 직접 켠 터미널에서 서버를 종료할 때는 그 서버 터미널의 Ctrl+C를 사용합니다. Hermes나 게이트웨이를 종료하는 절차가 아닙니다.

아래는 서버가 꺼져 있을 때의 PowerShell 예입니다.

```powershell
Set-Location 'C:\my vault\ME\1. Note\Hermes\Aiffel_Work\02_노드실습\딥리서치_에이전트\02_구현\전체화면_스파이크'
& '..\..\.venv\Scripts\python.exe' -m uvicorn '서버.앱:create_app' --factory --host 127.0.0.1 --port 8766 --workers 1
```

화면 코드를 바꾼 뒤에는 `화면/`에서 다음 빌드를 수행합니다. 빌드는 TypeScript/React를 브라우저용 파일로 변환하는 작업이지 EXE 제작이나 인터넷 배포가 아닙니다.
