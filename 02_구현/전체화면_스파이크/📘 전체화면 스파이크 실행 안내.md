이 조작은 **모델을 새로 호출하지 않는 코드 변환**입니다. 생성 파일은 각 데이터 루트의 `형식변환/` 아래 보존하고 다운로드명은 `연구보고서_<보고서ID>.html`/`.pdf`입니다. 기존 Markdown 이름·본문·해시는 변경하지 않습니다. 변환이 내용 오류를 정정하는 것은 아닙니다.

원문 상한은1MiB, PDF 동시 생성은1건입니다. 실제 변환 제한20초와 슬롯 대기·취소 후 안전한 자원 정리 시간은 구별합니다. OS 한글 글꼴과 앱 소유 스타일을 사용하며 외부 이미지/스크립트는 불러오지 않습니다. 한글·본문·인용·출처는 실제/긴 합성 파일에서 검사했지만 기본 한글 줄바꿈에 따라 어절이나 문단이 페이지 경계에서 이어질 수 있습니다. 근거는 `검증결과/보고서변환_최종검증요약.json`입니다.

실제 서버가 꺼져 있을 때만 다음 PowerShell 명령으로 켭니다. `.env`를 변경했다면 이 앱 서버만 다시 켜야 하며 Hermes 재시작은 필요하지 않습니다.

## 이전 시험용 스파이크 설명

이번 실행본은 **화면과 실행 제어를 검증하는 스파이크**입니다. 화면을 임시로 시험해 보는 구현이며, 실제 GPT 연구 결과가 아닙니다. FastAPI·LangGraph·SQLite·SSE·파일 저장은 실제로 연결했지만 모델 응답과 조사 자료는 명시적인 테스트 대역입니다. 실제 모델 요청은 0입니다. 선택 모델의 인증·무료 사용 적용·실제 연구·HTML/PDF 변환 등 정식 앱의 요구는 그대로 남아 있고, 이번 완료 범위에 포함하지 않습니다.

## 화면 사용

마을이 브라우저 작업 영역 전체입니다. 왼쪽 위 햄버거와 오른쪽 위 작은 `모의 응답` 표시, 하단 입력과 그 아래 얇은 `실행 타임라인` 손잡이가 기본적으로 보입니다. 상세나 큐·타임라인 때문에 마을 자체가 작아지지 않습니다.

- NPC 또는 말풍선: 해당 실행·버전의 사건을 중앙 팝업으로 엽니다.
- 작업대의 `...` 말풍선: 실제 코드 처리 사건의 입력·반환을 엽니다.
- `(클릭해서 더 자세히)` 글자뿐 아니라 말풍선 전체를 누를 수 있습니다.
- 제출 문서: 정확한 보고서 ID의 본문과 `Markdown 다운로드`를 엽니다.
- 팝업의 X 또는 Escape: 창만 닫습니다. 입력과 실행은 유지합니다.
- 긴 상세·기록은 팝업 안에서 스크롤합니다. 하단 입력은 계속 사용할 수 있습니다.

햄버거 메뉴에는 다음 기능이 있습니다.

| 메뉴 | 기능 |
|---|---|
| 장면 도구 | 에셋 모드의 이동·작업·문서 운반·처음으로 |
| 실행/큐 | 현재 질문·상태·계획·대기열·일시정지 사유와 `큐 계속` |
| 과거 기록 | 보존된 실행 카드 목록(질문·상태·자료·시각·보고서 줄) → 자세히 보기 또는 `기록 재생` → 같은 창의 목록 복귀 |
| 사건 기록 | 사건을 선택하여 고정된 원본 상세 열람 |
| 제어 도구 | 대역 응답 완료·이전 응답 해제·실패·불합격·현재 실행 취소 |
| 안내 | 모드·조작·보존 정책 안내 |

모드는 메뉴가 아니라 주소 끝으로 정합니다. `#/control`은 실제 연구에 연결된 실행 제어(8768의 기본)이고 `#/assets`는 합성 연출만 보여 주는 에셋 실험입니다. 에셋 실험은 서버 연구를 실행하지 않으며 지시 전송도 막힙니다.

## 실행 제어 시험 순서

1. 하단에 조사 지시 A를 입력하고 `지시 보내기`를 누릅니다.
2. 실제 로컬 그래프가 계획과 네 조사관 작업을 만듭니다. 응답은 시험 제어를 위해 대기합니다. 움직이는 것만 보고 실제 모델이 추론한다고 해석하지 않습니다.
3. 메뉴 → `제어 도구` → `현재 모두 완료`를 누르면 현재 대역 응답이 돌아오고 초안·검사·정본 저장·제출로 이어집니다.
4. 종합자가 문서를 운반해 놓으면 문서를 누릅니다. 뷰어와 다운로드는 같은 확정 Markdown입니다. 다운로드 파일을 다시 열어 볼 수 있습니다.

### 즉시 개입과 큐

- **일반 지시 B**: A가 기다리는 중에도 현재 계획·배정을 새 버전으로 바꿉니다. A의 원격 요청 내용을 소급 수정하는 기능이 아니라 새 지시를 적용하고 늦은 A의 결과가 정본을 덮지 못하게 하는 제어입니다.
- **`/큐 다음 조사`**: 현재 전체 보고서가 검사·저장·서버 제출된 뒤 진행합니다. 조사관 한 명의 응답이나 NPC 운반 완료를 기다리는 계약이 아닙니다.
- **이전 응답 돌려주기**: 이전 대기 응답을 실제로 반환시켜 적용 차단을 관찰합니다. 기록은 남지만 현재 원고·평가·정본에 섞지 않습니다.
- **실패 응답 / 불합격 초안 / 현재 실행 취소**: 해당 결과와 초안을 보존하고 큐를 일시정지합니다. 불합격 초안은 최종 문서로 제출하거나 다운로드하지 않습니다.
- **큐 계속**: 사용자가 명시적으로 일시정지를 풉니다. 정지 중 일반 지시를 보내도 기존 큐 정지는 자동으로 풀리지 않습니다.

새로고침은 상태 조회·사건 재구독만 하며 연구를 새로 시작하지 않습니다. 서버 재시작은 기록을 복원하되 진행 중이던 불명 작업은 `interrupted`, 큐는 정지로 남기고 대역/모델을 자동 재실행하지 않습니다.

## 객체별 시간과 기록 리플레이

최신 시간창에서는 지금 보는 실행 표시(`실시간`/`기록 재생`, 선택 상자는 없음)·재생/정지·단계 이동·현재 시각·시점 바·시간 눈금이 고정되고 **트랙 행만 스크롤**합니다. 아래쪽 조사관/문서 행을 보면서 시점을 바꿔도 같은 행을 유지합니다. 창 맨 위 경계에 커서를 대면 위아래 크기 조절 커서가 나오며 드래그로 높이를 바꿀 수 있습니다. 터치도 지원하며 경계를 Tab으로 선택한 뒤 위/아래 방향키(20px), Shift+방향키(50px), Home/End(최소/최대)를 사용할 수 있습니다. 접고 다시 열어도 현재 페이지의 선호 높이는 유지됩니다. 좁은/낮은 창이나 팝업 때문에 제한될 때는 입력·메뉴·닫기 공간을 남깁니다. 새로고침까지 높이를 저장하는 전역 설정은 추가하지 않았습니다.

현재 사용자 실행본에는 `[합성 시연] 마을 자료실과 정원의 협업·기록 리플레이` 완료 기록 한 건을 실제 UI 경로로 남겼습니다. 메뉴 → 과거 기록에서 이 실행의 `기록 재생`을 누르면 바로 재생을 시험할 수 있습니다. 이 한 건은 기존 기록을 지우지 않고 추가한 테스트 대역이며 실제 모델 호출은0입니다.

1. 입력 아래의 `실행 타임라인`을 눌러 하단 드로어를 엽니다. 입력은 펼친 창 위에 남아 있습니다. `기록 접기` 또는 드로어의 닫기로 접습니다.
2. 조정자·조사관1~4·종합자·코드·문서 트랙에 실제 구간이 표시됩니다. 아래 트랙은 창 내부에서 스크롤해 확인합니다. 막대를 누르면 같은 저장 사건의 원본 상세가 열립니다.
3. `단계 전체`는 대기를 포함한 단계 경과, `응답 대기`는 제공자 응답을 기다린 구간입니다. 둘은 겹치므로 더하지 않습니다. 트랙 옆 숫자는 겹침을 제외한 기록 경과이며 열린 구간은 `진행 중`, 값이 없으면 `미측정`으로 표시합니다.
4. `운반 연출`은2200ms의 화면 표현입니다. 측정한 모델/코드 처리시간이 아닙니다. 짧은 작업은 누를 수 있도록 최소 너비를 쓰지만 실제 시간 숫자를 늘리지 않습니다.
5. 메뉴 → 과거 기록에서 완료 실행의 `기록 재생`을 누른 뒤(타임라인에는 실행 선택 상자가 없습니다) 스크러버를 옮기거나 `재생`·`이전 단계`·`다음 단계`를 누릅니다. `재생`은 재생 중일 때 일시정지로 바뀝니다. 같은 시점의 NPC 위치·말풍선·보고서는 저장된 업무 사건을 기준으로 다시 구성합니다.
6. `실시간 복귀`는 실제 현재 상태로 돌아갑니다. 새로고침해도 선택한 실행/기록 시점은 같은 브라우저 세션에 보존됩니다.

**리플레이는 실행 되돌리기가 아닙니다.** 과거 시점을 보고 있어도 원래 실행·큐·완성 보고서는 바뀌지 않고 모델/그래프/도구를 재호출하지 않습니다. 지시·응답 해제·취소·큐 변경은 잠기고 작성 중인 입력은 보존됩니다. 새 지시를 보내려면 먼저 실시간에 복귀합니다.

시간은 실제 로컬 단계의 경과이며 순수 모델 연산시간/CPU 시간/속도 벤치마크가 아닙니다. 이 실행본에서는 사용자가 대역 응답을 돌려주기까지의 대기도 포함됩니다. 예전 기록에 세부 시간 측정이 없으면 사건 시점만 보여주고 정밀한 시간을 꾸미지 않습니다. 장면 재생은 녹화 영상이 아니라 동일 기록/시점에 따른 결정론적 연출입니다.
