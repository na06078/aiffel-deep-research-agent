# 스파이크 화면 기준

## 범위

Operate 모드의 두 개 프로토타입. 사용자는 무료 픽셀 마을·오른쪽 상세·하단 입력과 두 검증 질문을 확정하고 전체 제작을 승인했다. 새 브랜드·상업용 랜딩 페이지·시안 선택 작업이 아니다. 확정된 Tiny Town 계열 픽셀 마을의 작은 기능 장면을 직접 구성하며 이미지 생성 없이 code-led로 진행한다. 기존 작업/기술 명세가 요구사항 정본이다.

## Direction contract

### THESIS

작업의 이동을 작은 픽셀 마을에서 보고, 선택한 사건의 정확한 입출력을 옆에서 확인한다. 상단 통계 카드 나열이나 장식용 랜딩 헤더로 마을을 밀어내지 않는다.

### OWN-WORLD

Kenney 무료 16px 에셋의 초록 잔디·황토 길·작은 건물을 중심으로 한다. 작업 UI는 자연광 아래 PC에서 읽기 좋은 밝은 중성 바탕, 짙은 잉크 글자, 한 가지 녹색 조작색을 사용한다. 픽셀 이미지는 nearest·선명한 경계를 유지하고 본문은 시스템 한국어 UI 글꼴로 읽는다. 장식 이모지·네온·유리 효과는 쓰지 않는다.

### STORY

사용자는 에셋 모드에서 이동→작업→문서 운반을 조작하고, 제어 모드에서는 A 대기→B 개입→이전 응답 지연 도착→큐 제출 경계를 같은 입력창과 서버 기록으로 확인한다. 합성 자료임을 계속 표시한다.

### FIRST VIEWPORT

짧은 제목과 두 모드 전환, 그 아래 왼쪽의 큰 마을 장면·오른쪽 인스펙터, 장면 아래의 실험 조작과 입력. 화면을 카드 벽으로 만들지 않는다. 모바일는 장면→상세→입력의 문서 흐름으로 쌓고 넓은 창/좁은 창 모두 조작을 가리지 않는다.

### FORM

사용자가 확정한 좁은 기능 스파이크를 직접 구성한다. 임의의 새 시각 정체성·카탈로그 추첨은 추가하지 않는다. 기준은 실제 무료 에셋 표본과 확정 UI 배치이며 seed key는 해당 없음이다.
